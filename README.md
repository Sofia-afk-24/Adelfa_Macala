# Hypotenuse of a Right Triangle Calculator

## Description
This program calculates the hypotenuse of a right triangle
using input values and a math library.

## How to Run
1. Open the program file in PyCharm.
2. Run the program.
3. Enter the values for side a and side b.
4. Check the hypotenuse displayed on the screen.

## Input Needed
- a
- b

## Sample Output
Enter the length of side a: 67
Enter the length of side b: 69
The hypotenuse is: 96.18
